# moveElement = REPARENT; card-swap moved to separate swapElements gesture (spec Task 7/8 split)

## Rationale

The lift (a6d97deb) inside AstService.moveElement climbed to the common JSX ancestor and reordered sibling containers (card-swap) for a different-parent drag. This violated visual-foundation spec Part C: Task 7 defines moveElement-to-different-parent as REPARENT (child lands INSIDE target's parent, old parent empties), and Task 8 defines card-swap as a SEPARATE swapElements gesture. The lift broke the cross-parent reparent E2E (PI-5-DR-T2..T6: 'source did not land inside the right container'). DR-16/17 and DR-T2 are the SAME runtime gesture (inner-of-A dropped onto inner-of-B) with no intent signal, so swap and reparent are mutually exclusive for that gesture — the spec resolves it: moveElement reparents. review-cli quorum (codex gpt-5.5 + gemini, no dissent, no expert defended keeping the lift) confirmed: moveElement=reparent + card-swap via separate swapElements. Implemented: removed the lift from moveElement (cross-parent now reparents via the existing splice-into-target's-parent path); added AstService.swapElements (repurposes liftToCommonJsxParent to lift an inner-element pair to the outer-card swap unit) + ast:swapElements bridge handler + 7 unit tests; re-spec'd 8 flipped moveElement unit tests to reparent assertions; re-spec'd DR-16/17 E2E to reparent invariants. AGENTS.md updated.

## Evidence

Unit: 43 move+swap tests pass (26 move re-spec'd to reparent + 7 swap + cross-component/cross-file). Local gates: tsgo 0 errors, oxlint 0 errors, knip clean (swapElements wired). review-cli quorum unanimous for reparent+swapElements split.
