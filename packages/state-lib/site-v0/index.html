state-lib

Working home of the universal state toolkit (working name state): a small signal core, patch-emitting transactions, pluggable sync — specialised per project by a compiler, enforced by state lint, migrated into by state migrate. This site collects the research, the spec, the decisions and — coming — interactive comparisons, concept illustrations and REPL examples.
