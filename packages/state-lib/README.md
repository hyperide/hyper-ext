# state-lib

Working home of the universal state toolkit (working name `state`): research, specs, decisions, comparisons, and — later — the library packages themselves.

## Layout

- `REQUIREMENTS.md` — canonical requirement list (R1–R39, F1–F3, decision changes). The spec traces to these IDs.
- `DECISIONS.md` — decision log with supersessions.
- `docs/` — research brief, master spec, research reports.
- `docs/state-landscape.html` — the interactive competitor matrix ("The State of State", also published as a Claude artifact).
- `site/` — interactive documentation site (comparisons, concept illustrations, REPL examples with state visualisation and inline benches). Not started; see R35/R38.
