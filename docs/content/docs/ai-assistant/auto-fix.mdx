# Auto-Fix Feature

Hand off a failing component preview to the AI chat with one click.

## What is Auto-Fix?

When a component fails to build or render, the **Container Logs** panel captures
the error output. Auto-Fix takes that captured context, builds a prompt from it,
and opens the AI chat with the prompt prefilled — so you can review and send it
to the agent without copy-pasting logs by hand.

![Auto-fix feature](/screenshots/auto-fix.png)

## When to Use Auto-Fix

Auto-Fix is helpful for:

- Import errors (missing dependencies)
- Type mismatches
- Syntax errors in TSX
- Missing component props
- Runtime errors during render

## How It Works

1. A component fails to build or render
2. The error and surrounding log context are captured in the Container Logs panel
3. Click **Auto Fix** in the logs panel
4. A prompt is built from the error context and the AI chat opens with it prefilled
5. Send it to the agent — it inspects the relevant files and proposes edits
6. Review the proposed changes and apply them

## Auto-Fix Flow

### Step 1: Error Detection

When a component fails, the Container Logs panel captures:

- Error message
- Build / runtime output
- Surrounding log context

### Step 2: Prompt Hand-off

Auto-Fix assembles the captured context into a prompt and opens the AI chat with
it prefilled, so the agent starts with the full error in view.

### Step 3: AI Analysis

The agent examines the error, reads the relevant source files, and works out the
root cause and fix.

### Step 4: Proposed Edits

The agent proposes edits in chat. Review and apply them; the preview reloads on
the next build.

## Limitations

Auto-Fix cannot reliably solve:

- Complex business logic errors
- External API issues
- Database connection problems
- Build configuration issues

<Callout type="warning">
  Always review the proposed code. AI fixes may not be optimal or may introduce new issues.
</Callout>

## Manual Override

If the agent's fix doesn't work:

1. Read the error message in the logs carefully
2. Switch to Code mode (`4`)
3. Fix the issue manually
4. Return to Design mode

## Tips

1. **Hand off early** — Fixes are easier when errors are small
2. **Check the console** — More details may be in the browser console
3. **Give the agent room** — Follow up in the same chat if the first fix misses
4. **Report persistent issues** — Open a GitHub issue for repeated failures
