# CTO decision requests

**Status: mandatory.** The full text of this regulation now lives in the provisioned skill
`decision-request-discipline` (`~/.agents/skills/decision-request-discipline/SKILL.md`) —
the repo copy was a near-verbatim translation and was retired to this stub (HYP-949) to
avoid two sources of truth drifting apart.

Follow the skill: when to escalate, the self-check before asking, the consultation steps
(and how tool access varies by agent role), the mandatory Telegram channel, the 8-point
question format, the sibling/child-repo diff-posting recipe, and "PR or drop" requests.
The skill's glossary rule also carries the HyperIDE requirement to avoid invented
transliterated Anglicisms when writing in Russian.

If you are in an environment where `~/.agents/skills/` is not provisioned, run `rig apply`
(or your machine's provisioning step) to install the skill; this stub is the durable
pointer that keeps inbound links alive and tells you where the content went.
